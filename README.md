# ❄️ Expedição Polar | Vida Silvestre na Antártida

Página web moderna e responsiva desenvolvida como projeto prático do curso de Programação Web (Alura / Start). O projeto aplica conceitos fundamentais de **HTML5 Semântico** e **CSS3 Flexbox** para apresentar uma galeria interativa sobre a fauna e a preservação dos ecossistemas polares.

---

## 📋 Sobre o Projeto

A página foi estruturada com foco em alinhamento flexível, hierarquia visual e adaptação para diferentes tamanhos de tela:

* **Cabeçalho Flexível (`header`):** Barra de navegação fixa no topo com alinhamento distribuído entre logotipo e links de navegação.
* **Banner Principal:** Seção de destaque com imagem em alta resolução, sobreposição em gradiente e botão de chamada para ação.
* **Galeria de Cartões (`Flexbox`):** Exibição de cartões responsivos utilizando `display: flex`, `flex-wrap`, `gap` e efeitos visuais suaves ao passar o mouse (`:hover`).
* **Seção Informativa:** Bloco de destaque com dados ambientais sobre a importância climática das regiões polares.
* **Rodapé Estruturado (`footer`):** Fixado na base da página por meio de layout flexível em coluna (`min-height: 100vh`).

---

## 🚀 Tecnologias Utilizadas

* **HTML5:** Estruturação semântica do conteúdo (`header`, `nav`, `section`, `main`, `article`, `footer`).
* **CSS3:** Estilização completa com paleta de cores em `rgb()` e `rgba()`, Flexbox, sombras projetadas (`box-shadow`), ajuste de imagens (`object-fit: cover`) e responsividade (`@media queries`).
* **GitHub Pages:** Hospedagem gratuita do site estático.
